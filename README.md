# Trilogie 🎮

A curated repository of **downloadable Pygame projects** packaged as `.zip` files.

## What you'll find

- Ready-to-download game builds in `.zip` format
- Pygame-based projects inspired by the *Trilogie* world
- Lightweight releases you can quickly extract and play

## How to use

1. Open the repository's files or releases section.
2. Download the `.zip` package for the game you want.
3. Extract the archive.
4. Run the included game entry file (usually `main.py`).

## Contributing

If you have a Pygame build for this project, package it as a `.zip` and open a pull request.
