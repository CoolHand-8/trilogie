# Trilogie 🎮

A curated repository of **downloadable Pygame projects** packaged as `.zip` files.

## What you'll find

- Ready-to-download game builds in `.zip` format
- Pygame-based projects inspired by the *Trilogie* world
- Lightweight releases you can quickly extract and play

## ZIP package location

- Store downloadable archives in `/downloads/*.zip`
- Optionally attach the same `.zip` files to GitHub Releases for easier versioned downloads

## How to use

1. Open the repository contents (`/downloads`) or the Releases page.
2. Download the `.zip` package for the game you want.
3. Extract the archive.
4. Run the included game entry file (usually `main.py`).

## Contributing

If you have a Pygame build for this project:

1. Package it as a `.zip`.
2. Add it under `/downloads`.
3. Open a pull request with the new archive and a short gameplay description.
